# Kado Spesial untuk Mama 🎁

Website kado interaktif yang dibuat khusus oleh Bhian untuk Mama tercinta. Berisi surat digital romantis, efek animasi amplop 3D, konfeti, serta game bubble wrap kejutan.

## Fitur Utama
* **Animasi Amplop 3D**: Amplop interaktif yang bisa digeser (*drag-and-spring-back*) dengan efek buka tutup yang mulus.
* **Efek Kejut & Konfeti**: Ledakan partikel kotak-kotak kecil berwarna-warni saat amplop dibuka.
* **Surat Digital**: Tampilan surat interaktif dengan desain elegan.
* **Bubble Wrap Game**: 25 tombol bubble wrap interaktif dengan pesan "I Love You Mama".

## Teknologi yang Digunakan
* HTML5
* CSS3
* JavaScript

## Cara Menjalankan
1. Clone repositori ini atau unduh ke komputer lokal kamu.
2. Buka file `index.html` menggunakan browser favoritmu.
